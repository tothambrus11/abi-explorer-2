Language selector variants

C · C++ · Hylo: Nocturne palette. Each variant is live: click a language and the standard dropdown swaps to that language's list (Hylo has none yet, so it hides).

1 · Segmented current

The existing control with Hylo appended. Full accent fill on the selected segment.

2 · Pill tabs

Rounded track on --page, accent pill slides between options.

3 · Underline tabs

Lowest visual weight; accent only as a 2px underline. Fits a toolbar that already has borders everywhere.

4 · Ghost / outline

Detached buttons; selection = accent border + accent text on a 12% accent tint.

5 · Soft segmented

macOS-style: selection is a raised --baseline tab, no accent: accent stays reserved for focus/primary actions.

6 · Colour-coded chips

Each language gets one of Nocturne's categorical member colours (--c-1, --c-7, --c-3) as a dot + tint.

7 · Single combined dropdown

One control instead of two; standards are grouped by language. Fewest pixels, most clicks.

8 · Tiles

Two-line tiles with the driver name as a caption. Taller: better for a settings panel than the toolbar.

9 · Segmented + std as one unit

The standard dropdown is welded onto the end of the segmented control so language ⟶ standard reads as one phrase.

10 · Text field with suggestions

-x
-std=

Flag-shaped free-text inputs (mono, --page background, accent focus ring) with datalist autocomplete: mirrors the "Extra flags" field.

11 · Radio list

Native radios (accent-coloured) with descriptions. For the "More options" disclosure rather than the toolbar.

12 · Split button + menu

Compact accent button showing the current pair; the menu (styled like a tooltip/popover on --surface-1) picks language, with a sub-item for standard.

13 · With keyboard hints bonus

Ghost variant with an inline shortcut key; the kbd border uses --baseline, switching to accent when selected.
